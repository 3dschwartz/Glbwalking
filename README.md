Glbwalking lets you walk through 3D spaces – whether scanned or created – directly in your browser.  
The website only loads GLB files, which can be easily exported from common scanning apps like Polycam, Scaniverse, or KIRI Engine. Models from Blender can also be easily converted into the GLB format.  

Before loading a GLB file, it's a good idea to adjust the display:  
In particular, brightness and background color should be set beforehand to make the space clearly visible and help with orientation.
